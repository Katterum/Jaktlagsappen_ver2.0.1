## Jaktlaget 2.0.1

Bygger vidare pa 2.0.0.

Nytt i 2.0.1:
- Nytt defaultregister med 71 jaktpass.
- Bro hanteras separat som bromarkering och inte som jaktpass.
- Tidigare defaultpass ersatts vid forsta starten av versionen.
- Passlistan under installningar visar Placerad eller Ej placerad.
- Bla grans-waypoints visas i kartvyerna.
- Kartvyer for observationer, analys och matning har toggle for Visa alla pass.
- Befintlig historik och andra funktioner fran 2.0.0 bevaras.
